# Joel Herrera — Taller digital

Sitio personal construido con Astro. Reúne juegos, herramientas para el deporte, proyectos de comunidad y experimentos abiertos.

## Desarrollo

```sh
npm install
npm run dev
```

## Verificación

```sh
npm run check
npm run build
```

## Despliegue en Netlify

`netlify.toml` configura `npm run build` y publica `dist`, el directorio que genera Astro.
